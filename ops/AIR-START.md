# Start here in JetBrains Air

Open this folder in Air (Open → `TIVA\tiva-hq` in your user folder), start a
task, choose an agent (Claude or Codex), paste one of these jobs and press Run.
The agent asks before it runs commands on your PC: read what it wants to do,
then approve.

## 1. Build my Azure Windows workstation
> Read ops/founder-workstation/AGENT-TASK.md and do that task with me, step by step.

It signs you in to Azure in your browser, shows real prices, builds only after
you type YES, then checks everything works and shows you proof.

## 2. Check TIVA HQ
> Run npm install and npm run check, then tell me in plain words whether TIVA HQ builds and deploys cleanly, and what is on the pull request at https://github.com/dhanushanchan-hub/saas-admin-template/pull/4.

## 3. Explain what's in this project
> Read AGENTS.md, docs/AGENT_TEAM.md and the ops folder, then explain to me in simple words what TIVA HQ and each setup script does, and what is still waiting on me.

## If something goes wrong
Ask the agent: "Show me the exact error and explain it simply." Then send the
answer to Claude in your TIVA chat.
